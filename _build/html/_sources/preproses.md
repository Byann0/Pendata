# Pre-processing

**Data Preprocessing** merupakan salah satu tahapan dalam melakukan mining data. Sebelum menuju ke tahap  pemprosesan. Data mentah akan diolah terlebih dahulu. Data Preprocessing atau praproses data biasanya dilakukan melalui cara eliminasi data yang tidak sesuai. Selain itu dalam proses ini data akan diubah dalam bentuk yang akan lebih dipahami oleh sistem.

Pengertian lain menyebutkan bahwa data preprocessing adalah tahapan untuk menghilangkan beberapa permasalahan yang bisa mengganggu saat pemrosesan data. Hal tersebut karena banyak data yang formatnya tidak konsisten. Data preprocessing merupakan teknik paling awal sebelum melakukan data mining. Namun terdapat beberapa proses juga dalam data preprocessing seperti membersihkan, mengintegrasikan, mentransformasikan dan mereduksi data.

Melalui data preprocessing, memungkinkan proses mining akan berjalan dengan lebih efektif dan efisien. Karena data yang telah melalui Pra-pemrosesan data, merupakan data yang sudah melalui beberapa tahap pembersihan.

## Manfaat Data Preprocessing

Data preprocessing sangat penting dalam proyek berbasis data. Beberapa manfaat utama dari data preprocessing untuk proyek dan perusahaan meliputi:

- Mempermudah proses data mining
- Membuat data lebih mudah dibaca
- Mengurangi beban representasi data
- Mempercepat proses data mining secara signifikan
- Memudahkan analisis data dalam machine learning

## Tahapan Data Preprocessing

Proses kerja data preprocessing dibagi menjadi empat tahapan utama: data cleaning, data integration, data transformation, dan data reduction.

### 1. Data Cleaning

Pada tahap ini, data mentah dibersihkan dari ketidaklengkapan atau ketidakakuratan dengan mengisi nilai yang hilang, mengurangi data berisik (noisy data), dan menyelesaikan inkonsistensi. Data juga dapat diproses lebih lanjut melalui metode seperti binning, regression, atau grouping, untuk merapikan dan menyusun data dalam segmen-segmen yang lebih seragam.

### 2. Data Integration

Data integration adalah tahap di mana data dari berbagai sumber digabungkan menjadi satu dataset yang utuh. Proses ini memerlukan penyeragaman format data, penghapusan atribut yang tidak relevan, dan deteksi nilai yang konflik. Data integration bertujuan untuk menghasilkan data yang konsisten dan dapat diolah lebih lanjut.

### 3. Data Transformation

Pada tahap ini, data dinormalisasi dan digeneralisasi. Normalisasi bertujuan untuk menghilangkan duplikasi data, sedangkan generalisasi menyamakan format data. Proses ini mencakup langkah-langkah seperti:

- Aggregation: Menggabungkan data dengan format seragam.
- Normalization: Menjadikan data berada dalam skala yang teratur untuk perbandingan yang akurat.
- Feature Selection: Memilih variabel yang paling relevan untuk analisis dan model machine learning.
- Discretization: Mengelompokkan data ke dalam interval yang lebih kecil, seperti rentang waktu tertentu.
- Concept Hierarchy Generation: Menambahkan hirarki baru dalam dataset.

### 4. Data Reduction

Tahap terakhir adalah data reduction, atau pengurangan jumlah data. Dalam data mining, data yang terlalu besar dapat mempengaruhi tingkat akurasi. Oleh karena itu, sampel data diperkecil tanpa mengubah hasil analisis. Ada tiga teknik utama yang dapat digunakan untuk data reduction:

- Dimensionality reduction: Mengurangi jumlah dimensi data.
- Numerosity reduction: Mengurangi jumlah data.
- Data compression: Mengompres data untuk efisiensi penyimpanan.

## Kesimpulan

Data preprocessing merupakan langkah penting dalam analisis data yang menyaring data dari berbagai sumber dan menyeragamkan formatnya. Dengan proses ini, bisnis dapat memperoleh hasil yang lebih akurat untuk mendukung perencanaan, pengembangan, dan pemahaman terhadap target bisnis. Bisnis juga harus memperhatikan data keuangan dan mencatatnya secara rinci dalam pembukuan, yang dapat dipermudah dengan aplikasi seperti Accurate Online untuk proses pembukuan yang cepat, akurat, dan otomatis.
